## v1.0.1 — 图标与桌面快捷方式

在 v1.0.0 基础上补齐应用图标与桌面入口。原生 Win32（C + GDI/GDI+），单文件 exe，免安装。

### 本次内容

- 内嵌多尺寸图标：16 / 24 / 32 / 48 / 64 / 256（256 为 PNG 压缩），窗口大小图标（`WM_SETICON`）与托盘图标复用同一套，资源管理器、任务栏、托盘显示一致
- 托盘菜单新增「创建桌面快捷方式」：`IShellLinkW` + `IPersistFile` 生成「桌面布局.lnk」，指向当前 exe 并复用内嵌图标（`SetIconLocation(exe, 0)`）
- 桌面路径由 `SHGetKnownFolderPath(FOLDERID_Desktop)` 解析，桌面被重定向时同样有效，不硬编码
- 同名 `.lnk` 已存在且指向其它程序时不覆盖，状态栏提示；仅覆盖本程序生成的快捷方式
- 图标源（`assets/app_icon.py`，Pillow 8× 超采样）与 `.ico` / `.rc` / `.obj` 一并入库，`build.bat` 直接链接 `.rsrc` COFF 对象，无需 `rc.exe`

### 体积

- `DesktopLayoutNative-v1.0.1-win-x64.zip`（exe 解压后 175,616 B）
- exe 128,000 → 175,616 B（+47,616 B）：图标资源 +45,568 B，代码 +2,048 B（无图标对照构建 130,048 B）
- exe SHA256：`7D15D631A7E3DA843EB62CE81F84392F886D4C59037634263A1F649528CDFA26`

### 启动代价

- 启动到窗口可见：加图标前 148.5 ms、加图标后 151.8 ms（各 5 次中位），差值在测量噪声内
- 进程周期计数 67.16M → 68.63M（+2.2%，约 0.7 ms）
- 常驻开销无变化：GDI / USER 对象 53 / 19、线程 5、句柄 151，空闲 CPU 0.00 ms/s，均与 v1.0.0 相同

### 系统要求

- Windows 10 / 11（x64）；无需 .NET、Python 或 VC++ 运行库
- 桌面由 Explorer 管理；使用前关闭「自动排列图标」
- 多显示器还原要求目标显示器在线

### 已知限制

- **Win11 托盘图标可能落进「隐藏的图标」溢出区**，需手动到 设置 → 个性化 → 任务栏 → 其他系统托盘图标 里置顶
- 桌面快捷方式名称固定为「桌面布局.lnk」；桌面已有指向其它程序的同名 .lnk 时不会覆盖，需先改名或删除
- 撤销只有一级（最近一次应用前的快照），再次应用会覆盖
- 布局中记录但桌面上已删除 / 重命名的图标会被跳过并计数
- 不处理「显示桌面图标」关闭、虚拟桌面切换等 Explorer 状态变化
- 版本号以 Release tag 为准；源码内不重复内置版本串

### 安装

下载 zip 解压，双击 `DesktopLayoutNative.exe`。数据写入 `%LOCALAPPDATA%\DesktopLayoutNative\data\`，卸载时删除该目录即可。
