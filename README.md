# 桌面布局 · DesktopLayoutNative

把 Windows 桌面图标的位置存成「布局」，随时一键还原。原生 Win32（C + GDI/GDI+），单文件 exe，无运行时依赖。

**为什么不用手动拖图标**：桌面图标被「自动排列」打乱、换分辨率后位置全丢、临时演示想恢复原样——手动摆一遍几十个图标很费时。这个工具把「当前位置」存成命名布局，应用前自动备份，随时可撤销。

```
┌─ 桌面布局 ─────────────────────────────┐
│ 布局名称              图标  修改时间    │
│ 当前布局              46    11-04 09:06│
│ 演示布局              42    11-04 09:07│
│ ┌────────┐┌────────┐┌────────┐┌──────┐ │
│ │  应用  ││  撤销  ││  重命名 ││ 删除 │ │
│ └────────┘└────────┘└────────┘└──────┘ │
│ ☑ 开机自动启动            ☑ 删除前确认 │
│ ● 就绪                                 │
└────────────────────────────────────────┘
```

## 快速开始

从 [Releases](https://github.com/Simiely/DesktopLayoutNative/releases) 下载 `DesktopLayoutNative-v1.0.0-win-x64.zip`，解压后双击 `DesktopLayoutNative.exe` 即可。

> 使用前请在桌面右键菜单中**关闭「自动排列图标」**，否则系统会拒绝还原位置。
> 环境要求：Windows 10 / 11（x64），无需安装 .NET / Python / VC++ 运行库。

从源码构建见 [DEVELOPMENT.md](DEVELOPMENT.md)：

```bat
build.bat
:: 产出 dist\DesktopLayoutNative.exe
```

## 主要能力

| | 说明 |
|---|---|
| 保存布局 | 读取资源管理器当前所有桌面图标的位置，存成命名 JSON（含显示器、DPI、格位） |
| 应用布局 | 先自动快照当前布局再还原；名字或显示器不匹配的图标会计入差异报告 |
| 撤销 | 一键回到应用前的快照（单级撤销） |
| 多显示器 / DPI | 记录每枚图标所在显示器与位置，按当前 DPI 换算 |
| 托盘常驻 | 关闭主窗口即收进托盘；托盘菜单支持保存、应用、撤销、打开、退出 |
| 开机自启 | 勾选「开机自动启动」写入 `HKCU\...\Run`（带 `--tray`，开机不弹窗） |
| 删除确认 | 默认开启二次确认；可在状态栏右侧开关，选择持久化到 `settings.json` |
| 命令行 | `--save` / `--apply` / `--undo` / `--list` / `--rename` / `--delete` / `--swap-test` |

## 版本

当前 **v1.0.0**。版本号以 Release tag 为准（源码不重复内置版本串，避免与构建产物漂移）。

## 构建

需要 [zig](https://ziglang.org/) 0.17.0（自带 mingw-w64 与 libc，无需安装 MSVC）：

```bat
build.bat                     :: 默认调用 PATH 中的 zig
build.bat D:\zig\zig.exe      :: 或指定 zig 路径
```

产物为 `dist\DesktopLayoutNative.exe`（约 125 KB，GUI 子系统）。

## 已知限制

- 桌面必须由 Explorer 管理；开启「自动排列图标」时应用会失败并提示。
- 应用布局只移动**已存在**的图标；布局里记录但桌面上已删除的图标会被跳过并计数。
- Win11 的托盘图标可能被收进「隐藏的图标」溢出区，需要到 **设置 → 个性化 → 任务栏 → 其他系统托盘图标** 里手动置顶。
- 撤销只有一级（最近一次应用前的快照）；再次应用会覆盖快照。
- 不处理「显示桌面图标」关闭、虚拟桌面切换等 Explorer 状态变化。
