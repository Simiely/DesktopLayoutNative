# 使用指南

## 启动

双击 `DesktopLayoutNative.exe`。主窗口固定 500 × 400，打开时列出 `layouts` 目录里的布局。

- 关闭窗口 = 收进托盘，不退出；要真正退出请用托盘菜单「退出」。
- 托盘图标：左键单击打开主界面，右键弹出菜单（保存当前布局 / 使用布局 / 撤销 / 打开主界面 / 退出）。
- Win11 托盘图标可能进「隐藏的图标」溢出区：到 **设置 → 个性化 → 任务栏 → 其他系统托盘图标** 把「桌面布局」置顶。

## 保存 / 应用

1. **保存**：窗口底部输入布局名（默认为「当前布局」），点「保存」。会记录当前桌面每枚图标的坐标、所在显示器与格位。
2. **应用**：列表选中一个布局，点「应用」。应用前会自动把当前桌面存为撤销快照；名字不匹配或已删除的图标会跳过并在状态栏报告数量。

> 桌面右键 → **查看 → 取消勾选「自动排列图标」**。开启自动排列时应用会失败并提示，这是 Explorer 的限制。

## 撤销

应用布局后，点「撤销」即可回到应用前的状态（只保留最近一次应用前的快照；再次应用会覆盖）。

## 删除与确认

- 默认开启「删除前确认」：点删除会弹出圆角确认框，按钮为「取消 / 删除」，Esc / Enter 都等于取消。
- 状态栏右侧的「删除前确认」勾选框可关闭确认：关闭后删除立即生效，状态栏显示「已删除「名称」」，仍可用「撤销」恢复桌面（删除布局文件本身不进回收站）。
- 该开关保存在 `data\settings.json`，重启后保持。

## 开机自动启动

界面勾选「开机自动启动」即在 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 写入：

```
"<安装路径>\DesktopLayoutNative.exe" --tray
```

取消勾选即删除该键值。`--tray` 表示开机静默启动，不弹主窗口。

## 数据存放

```
%LOCALAPPDATA%\DesktopLayoutNative\data\
├── layouts\*.json           布局文件（可直接备份 / 拷贝）
├── undo\undo_snapshot.json  撤销快照
├── layout_current.json      最近保存
└── settings.json            界面设置（confirm_delete）
```

删除 `data` 目录即恢复出厂状态（布局和设置都会丢）。

## 命令行

GUI 子系统程序会附加到调用它的控制台，可直接在 cmd / PowerShell 使用：

```bat
DesktopLayoutNative.exe --save "%USERPROFILE%\Desktop\my-layout.json"
DesktopLayoutNative.exe --apply "%USERPROFILE%\Desktop\my-layout.json"
DesktopLayoutNative.exe --undo
DesktopLayoutNative.exe --list
DesktopLayoutNative.exe --delete "%USERPROFILE%\Desktop\my-layout.json"
DesktopLayoutNative.exe --tray
```

加 `--result out.json` 可把结构化结果写到文件，便于脚本判断。

## 系统要求

- Windows 10 / 11，x64；无需 .NET、Python 或 VC++ 运行库。
- 多显示器、125% / 150% 缩放下均可保存还原；跨显示器还原要求目标显示器仍在线。
- 弹窗圆角为分层窗口逐像素绘制，Win10 与 Win11 表现一致；阴影由系统提供。

## 常见问题

| 现象 | 处理 |
|---|---|
| 应用失败，提示「自动排列图标」 | 桌面右键 → 查看 → 取消「自动排列图标」 |
| 托盘里找不到图标 | Win11 溢出区；到任务栏设置里置顶 |
| 还原后部分图标没动 | 这些图标在保存后被重命名 / 删除了，属预期跳过 |
| 双击 exe 没反应 | 已在运行（单实例）：检查托盘或任务管理器 |
