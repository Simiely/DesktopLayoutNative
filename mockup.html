无法圆角化清单

对象原因处理
真实托盘菜单（TrackPopupMenu）系统菜单窗口，不自绘改不了圆角/字体按约定不自绘；Win11 系统自带圆角
原生标题栏 / 窗口外框DWM 绘制Win11 自动圆角；Win10 直角，不额外 SetWindowRgn
HTML 内嵌的历史截图内容截图里的旧 UI 本身是直角只保证截图卡片外框圆角
文本字形 / 图标像素非矩形元素不适用
输入框内部的原生 EDIT 客户区系统子窗口，方角外壳圆角 + EDIT 内缩 2px，填充色相同，视觉无缝

C 版 4× 特写：shots/ui_corners_4x.png（12 格：卡片四角 / 输入 / 按钮 / 选中行 / 复选框 / 圆点 / 详情，4× 最近邻放大，标注「已圆」）；本稿特写：shots/mockup_corners_4x.png。
